# Changelog

## v2.1.0 (2026-06)

- PowerShell native file dialogs (no tkinter thread issues)
- Light/dark theme toggle with persistence
- Audio format conversion tab (mp3, wav, aac, m4a, ogg, flac)
- Batch extraction with unified file list
- Video preview with visual trim controls
- Keyboard shortcuts panel (`?` key)
- First-run onboarding guide
- Download history panel
- System notifications on completion
- Estimated time remaining during extraction
- Playlist/collection download support
- Modular project structure (audioextract package, Jinja2 partials, JS modules)
- MIT LICENSE, pyproject.toml, CI/CD, tests

## v2.0.0 (2026-05)

- Web-based UI with Flask + Alpine.js
- Douyin/TikTok direct parsing (no cookies needed)
- Bilibili and YouTube via yt-dlp
- Drag-and-drop file support
- Cancel extraction button

## v1.0.0 (2026-05)

- Initial release
- Tkinter GUI
- Local file audio extraction via ffmpeg
- URL extraction via yt-dlp
